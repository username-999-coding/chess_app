# Python Chess Game ♟️

A GUI-based (Graphical User Interface) chess game built using **Python**, the **Tkinter** library, and **Pillow (PIL)**. This project was one of my first programming endeavors, featuring a custom AI system and a complete implementation of chess rules.

---

## 🌟 Key Features

1. **Complete Chess Rules:**
   - Movement for all chess pieces
   - Castling (kingside and queenside)
   - En Passant
   - Pawn promotion
   - Detection of Check, Checkmate, and Stalemate
2. **Game Modes & AI:**
   - AI Difficulty Levels: Easy, Medium, and Hard (powered by the Minimax algorithm with Alpha-Beta Pruning)
   - 1v1 Mode (Human vs. Human)
3. **Customization & Interface:**
   - Color theme selection (Light or Dark)
   - Automatic board flipping when playing as the Black (Dark) side
4. **Game Utilities:**
   - Game timer
   - Resign button
   - Move history log
